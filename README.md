# search-radar

Steuer- und Ergebnisseite fuer den privaten ThinkPad-Scanner (Repo `Scrapper`).
Reines HTML ohne Geheimnisse: die Seite fragt mit einem Fine-grained Token, das nur im
Browser gespeichert wird, die GitHub-API des privaten Repos ab.

GitHub Pages: Settings > Pages > Deploy from a branch, Branch `main`, Ordner `/ (root)`.
